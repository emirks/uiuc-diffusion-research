DINO-Basis Operator Signal

An appearance-free description of a video's transition — 44 channels laid out on the LTX-2 VAE latent grid, read out of DINOv2 patch tokens. One field per clip, aligned cell-for-cell with the latent the model trains on, so it attaches as a conditioning stream that carries what changes without carrying what the scene is.

01 · Extraction pipeline

From a reference clip to a latent-aligned field

The signal never touches generated pixels. It is computed once per real clip, from a small set of frames chosen to line up with the VAE's temporal chunks, then pooled onto the exact latent grid the transformer sees.

02 · Geometry & frame selection

Adaptive: the grid is read from each clip's own latent

There is no fixed size. Each clip's field shape is derived from its VAE latent — one signal timestep per latent frame, one signal cell per latent cell — so the same definition covers 121-frame portraits and 33-frame landscapes alike.

Spatial grid

Latent grid H_lat = round(H/32), W_lat = round(W/32). DINO runs at twice that (2H_lat × 2W_lat patches); each 2×2 patch block is mean-pooled into exactly one latent cell — the cell's 32-px footprint tiled by two 14-px patches at the 28/32 resize.

non-÷32 inputs (e.g. S4 832×464) are cover-scaled and center-cropped to (32·H_lat, 32·W_lat) first — reproducing the ctt_v2 encode's own 16-row crop — so the cells stay pixel-aligned with the training latent. S6 (EffectData) is native VAE-legal — all four resolutions are already ÷32, so the crop is a no-op; H_lat can be odd (33, 39) and the 2×2 pool is unaffected (it acts on the even 2H_lat patch grid).

Shapes in practice

S0 / S1 / S2 · 121f 640×480(16, 20, 15, 44)
S4 · 33f 832×464(5, 14, 26, 44)
S6 · 81f (4 native)(11, 22|33|39, 22|33|39, 44)

The extractor asserts each computed shape against the clip's shape field in samples.jsonl (S6 against its own ROSTER entry), so a field can never silently drift off the training grid.

Five groups, from content state to color transport

Temporal convention

The frame-pair channels (G2, G3, G5-dLab) are forward differences assigned to timestep ℓ, giving T_lat − 1 native values; the last timestep replicates the previous one. Zeros are never padded in — a zero would assert a frozen scene.

04 · Frozen parameters

Fixed once, applied everywhere

Every constant below is frozen across all strata, so the signal is a comparable instrument rather than a per-clip fit.

Correspondence & readout

  • Backbone — DINOv2-base, 14-px patches, L2-normalised; CLS + register tokens dropped.
  • Resize — grid-commensurate 28/32 of the latent-pixel size (net direct resize to 2·latent·14 px).
  • Match window — radius r = 5 on the 2× patch grid, centered on the source cell.
  • Softmax temperature — τ = 0.07, calibrated once so the entropy channel is neither saturated nor flat.
  • Confidence — mean of the top-3 cosines at the match; forward–backward round-trip > 1 patch ⇒ conf = 0.
  • Entropy — normalised by log |valid window| per location.

State projection (G1)

  • PCA — 768 → 32, frozen: fit once on 672k pooled+normalised cell vectors from S0 / S1 / std121.
  • Captured variance — 0.45 EVR on the fit set; reused unchanged on every stratum.
  • Held healthy under shift — captured-variance share stayed 0.82–0.90× of the S0/S1 baseline on procedural S2 and effect-heavy S4, so the frozen basis was kept (no refit).
Why frozen

A per-corpus refit would rotate the basis toward S2's 69% weight and make G1 values incomparable between train and eval. The instrument stays fixed.

05 · Endpoints & sidedness

The endpoints are the same; only five channels feel the difference

Sidedness is a property of the training mask — two-sided conditions on both endpoints (p2), one-sided on the start alone (p1) — not a property of the signal. The signal always takes A = frame 0 and B = frame T−1. Structurally, only the channels that reference an endpoint are coupled to sidedness; the rest are invariant by construction, and any split you measure in them is a property of the clips, not the metric.

nu stays two-sided — for every clip

nu = 1 − max(s_A, s_B) measures transient novelty (content in neither final state) and is kept universal. A one-sided variant 1 − s_A was tested and rejected: it is redundant with the existing s_A channel and renames "departure from base" as novelty. The distinct signals already coexist — s_A carries effect magnitude, nu carries the off-endpoint transient.

06 · Settled decisions

What was tested and closed

The signal is frozen at 44 channels. Three questions were resolved with measurements, not preference.

Kept

nu = 1 − max(s_A, s_B)

Two-sided form for all clips. The one-sided form (1 − s_A) duplicates s_A and loses the transient-novelty signal.

Rejected

ν′ span-residual

Distance to the A↔B feature-blend adds ~nothing on real pixel dissolves (r = 0.99 with nu) — a crossfade is not a lerp in DINO's nonlinear space.

Kept

Frozen PCA, no refit

G1 captured-variance stayed 0.82–0.90× baseline on S2 / S4 — well above the collapse threshold — so the basis was reused, keeping the instrument comparable.

S6 cross-orientation — trainer warning. An S6 row pairs a target with a different-subject reference, so the two can carry different grid orientations (e.g. the transpose pair (11,22,33) vs (11,39,22)). A row's shape describes only the target. Any consumer conditioning on the reference's signal must handle cross-shape fields and key each stem's shape by its own ROSTER entry — never the row's target shape.

  • dino_raw/<id>.npz — raw DINOv2 tokens (T_lat+1, 2H_lat, 2W_lat, 768) fp16, with frame & crop metadata. ~2 TB — kept so a new channel is a re-read, not a re-encode.
